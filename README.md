# Chess Online (P2P)

GitHub Pages で配信する、外部データベース・対戦サーバーなしのオンラインチェスです。通信にはブラウザ標準の WebRTC DataChannel を使い、対局データは2台のブラウザ間で直接送受信します。

## 機能
- 作成側が白、参加側が黒になる1対1対局
- WebRTCによるP2P通信
- 接続コード（Offer / Answer）のコピー・貼り付けによる手動接続
- ルームパスワードによる接続時照合（SHA-256ハッシュをP2P経由で照合）
- 持ち時間（1 / 3 / 5 / 10 / 15 / 30分）
- リアルタイム盤面・棋譜同期
- 定型文チャット、自由入力チャット
- 投了、チェックメイト、ステイルメイト、戦力不足、時間切れ

## 接続手順
1. 両者が GitHub Pages の同じページを開く。
2. 作成側が「接続コードを作成」を押し、表示されたコードを参加側へ送る。
3. 参加側がコードを「作成者から受け取った接続コード」に貼り、「応答コードを作成」を押す。
4. 参加側が応答コードを作成側へ送る。
5. 作成側が応答コードを貼り、「応答を適用して接続」を押す。
6. P2P接続が成立すると対局画面へ移る。

## 接続上の重要な制約
- GitHub Pages は静的ファイル配信サービスであり、サーバー処理やルーム情報の保管は行いません。
- Offer / Answer の交換は手動です。自動ルーム検索・自動マッチングはありません。
- この実装は STUN / TURN サーバーを一切設定していません。ICE候補はブラウザが取得できる直接接続候補のみです。そのため、同一LANなどでは接続できる場合がありますが、異なるネットワーク・携帯回線・NATやファイアウォールの条件によっては接続できません。
- 「外部サービスなし」を優先した構成であり、インターネット上の任意の2端末間で接続できることは保証しません。任意のネットワーク間での安定接続には通常STUN、場合によってTURNが必要です。
- 対局中に片方がページを再読み込みすると、接続は失われます。再接続・対局復元機能はありません。
- WebRTC DataChannel の通信はブラウザが暗号化しますが、接続コードは第三者に公開しないでください。

## 公開
GitHub Pages を有効化し、`main` ブランチの `/ (root)` を公開元に指定してください。ビルドやサーバー設定は不要です。
